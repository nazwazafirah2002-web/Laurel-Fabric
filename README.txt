LAUREL FABRIC — WEBSITE COMPANY PROFILE

Website memiliki tepat dua halaman:
- index.html       : halaman Home
- about.html       : halaman About Us
- css/style.css    : styling website dan responsive layout
- js/script.js     : interaksi menu mobile dan tahun footer

Informasi usaha:
Laurel Fabric menawarkan jasa menjahit kain perca serta menjual kain bordir dan kain mentahan.

Cara menjalankan:
1. Download dan ekstrak file ZIP.
2. Buka folder laurel_fabric_website di Visual Studio Code.
3. Jalankan index.html menggunakan Live Server, atau buka langsung di browser.

Navigasi:
- Menu Home dan About Us menghubungkan dua halaman.
- Menu Layanan, Produk, dan Kontak mengarah ke bagian terkait di halaman Home.
- Dari halaman About Us, menu Layanan, Produk, dan Kontak juga mengarah ke bagian terkait di Home.
